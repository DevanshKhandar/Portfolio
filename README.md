# Devansh Khandar - Personal Portfolio

A cinematic, highly interactive personal portfolio designed for an Electronics Engineer. It showcases a strong focus on embedded systems, robotics, edge AI, and hardware design.

## 🚀 Features
- **Cinematic Launch Sequence:** An immersive HUD-style intro sequence.
- **Interactive Particle Canvas:** A background constellation that reacts to cursor movement.
- **Light & Dark Themes:** Fully responsive and premium themes tailored for different environments.
- **Project Showcase:** Detailed breakdowns of hardware, IoT, and ML projects with architectural diagrams and GitHub source links.
- **Professional Timeline:** Expanding cards documenting experience and leadership roles (e.g., DJS ARYA CanSat team).

## 🛠️ Technology Stack
- **HTML5:** Semantic structure and layout.
- **CSS3 (Vanilla):** Custom properties, CSS Grid/Flexbox, keyframe animations, and glassmorphism.
- **JavaScript (Vanilla):** DOM manipulation, Canvas API for particle physics, Intersection Observers for scroll animations, and session storage for intro state management.

## 📂 Project Structure
- `index.html` - The main structure of the portfolio.
- `style.css` - All styling, responsive design rules, and light/dark theme overrides.
- `main.js` - Logic for the launch sequence, scroll reveals, particle canvas, and theme toggling.
- `privacy.html` / `terms.html` - Legal pages for the portfolio.
- `/assets/` - Directory for images, certificates, resume PDFs, and the launch video.

## ⚙️ Running Locally
Simply open the `index.html` file in any modern web browser to view the site. No build tools or servers are required.
